## 2. Module ↔ peer practice (what steering is signing)

| R1 module (§3) | Botswana lesson | Panama lesson | Zimbabwe differentiator |
|----------------|-----------------|---------------|-------------------------|
| **National overview** | Plot grid health + ground-truthing cadence | Ministry overview tied to **reporting calendar** | Corpus health panel (field / layers / exports), not telemetry KPIs |
| **Evidence registry** | Grid plot ID discipline | Farm/basin traceability in reports | One registry: LDN + soil + drylands; CEID → unit layer |
| **Verification workspace** | TWG review of anomalies | Local LDN goal reports upstream to ministry | District → national → **lock**; audit log (`005`) |
| **National layers → LDN units** | 1OAO + national six-class context | LC **2000–2021** national legend | `LDN-NAT-ALL` + CEID QA; Area unit **Q1** |
| **Pressures / interventions** | — | Basin narrative with spatial context | **PRESS-*** + **INT-*** EMA zips in one catalogue |
| **Analytics → LC transitions** | National class consistency | Participatory legend extensions | **`LC-NAT-STACK`** + **S10** (not field-only SO1-1) |
| **Reporting desk** | National data in PRAIS, not default-only | Institutionalized export handoff | `EXP-SO1-*` bundle + manifest hashes; 3-row lock **pilot** |
| **Drylands (ILUP)** | Dryland monitoring patterns | — | Same evidence model as LDN in registry |
| **Administration** | — | Platform survives project (**2030** horizon) | Supabase **S2** + EMA ICT ownership |
